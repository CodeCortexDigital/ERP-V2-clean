QUICK REFERENCE - API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════════════

AUTHENTICATION:
   POST   /api/auth/login/                    - Login
   GET    /api/auth/me/                       - Current user
   POST   /api/auth/logout/                   - Logout

STUDENTS:
   GET    /api/auth/students/                 - List students
   POST   /api/auth/students/                 - Create student
   GET    /api/auth/students/{id}/            - Get student
   PUT    /api/auth/students/{id}/            - Update student
   DELETE /api/auth/students/{id}/            - Delete student
   GET    /api/education/students/student-360/{id}/ - Full profile

ATTENDANCE:
   GET    /api/auth/attendance/               - List attendance
   POST   /api/auth/attendance/mark/          - Mark attendance
   GET    /api/auth/attendance/report/        - Attendance report

EXAMS:
   GET    /api/auth/exams/                    - List exams
   POST   /api/auth/exams/                    - Create exam
   POST   /api/auth/exams/results/            - Enter results
   GET    /api/auth/exams/results/student/{id}/ - Student results

FINANCE:
   GET    /api/auth/invoices/                 - List invoices
   POST   /api/auth/invoices/                 - Generate invoice
   POST   /api/auth/payments/                 - Record payment
   GET    /api/auth/fee-structures/           - Fee structure

COMMUNICATION:
   POST   /api/communication/messages/        - Send message
   GET    /api/communication/templates/       - Get templates
   POST   /api/communication/whatsapp/test/   - Test WhatsApp

ADMISSIONS:
   GET    /api/auth/applicants/               - List applicants
   POST   /api/auth/applications/             - Submit application
   POST   /api/auth/applications/{id}/convert/ - Convert to student

ANALYTICS:
   GET    /api/analytics/student/{id}/        - Student insights
   POST   /api/analytics/batch-risk-assessment/ - Batch risk analysis

EMERGENCY FIXES (If something breaks)
═══════════════════════════════════════════════════════════════════════════════════════

API Connection Issue:
   → Check backend: python manage.py runserver
   → Check URL in .env: VITE_API_URL=http://localhost:8000
   → Check CORS in backend settings

Auth Issue:
   → Clear localStorage: localStorage.clear()
   → Re-login with admin@code.com / admin123
   → Check token in Network tab

Data Not Loading:
   → Check console for errors
   → Verify API endpoint returns data via Postman
   → Check model has data in Django admin

Form Not Submitting:
   → Check required fields
   → Check validation errors in console
   → Verify CSRF token (if used)
