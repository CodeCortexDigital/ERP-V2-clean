3. 🟡 Issues Found
Moderate:
1. Executive dashboard APIs disconnected — analyticsService.getExecutiveDashboard() is defined in frontend/src/services/analytics.service.ts:40 but never called by any page. Two backend executive_dashboard views exist (one in accounts/views.py, another in analytics/views.py) — both provide rich 12-month trend data, ML risk assessment, and smart insights — but the frontend ignores them entirely and computes its own stats from individual raw API calls.
2. Employee attendance is hardcoded to 0 — dashboard_attendance_stats at views.py:597-601 always returns { total: 0, present: 0, present_pct: 0 }. The employee attendance feature is not implemented on the backend.
3. "Present Employees" widget is fake — DashboardPage.tsx:101-107 maps all teachers as present instead of querying actual attendance records. All employees always show as present.
4. Monolithic component — No child widget components extracted. Impossible to test or reuse independently.
 5. No role guard on /dashboard — App.tsx:215 has no RoleBasedRoute. Any authenticated user (student/teacher/parent) can access it.
 6. Duplicate executive_dashboard views — Identical functionality in two separate files with slightly different response shapes.
 7. Duplicate bulk_attendance_working function — Two identical copies at views.py:1202 and views.py:1262.
 8. views_backup.py exists — Obsolete backup shadowing the active views file.
 9. Stub dashboards never used — CurriculumDashboard.tsx, AttendanceDashboard.tsx, AssignmentDashboard.tsx are all unreachable placeholders.
10. ExamDashboard duplicates — Two competing versions at exams/ExamDashboard.tsx and exams/dashboard/ExamDashboard.tsx.
4. 💡 Suggested Improvements
